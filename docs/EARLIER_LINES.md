# Earlier lines and where they went

Several projects here continue earlier attempts that ran with other data or tools and did not reach a confirmed result. This page maps each earlier line to the folder that now holds its method. No results from those attempts are published here, and none should be assumed. Earlier criteria are reference only; every restart needs a new preregistration.
